## 🛠️ Sobre el Proyecto

**Challenge Backend** es una API RESTful desarrollada en **Node.js** con **TypeScript**, diseñada para la gestión y consulta centralizada de la flota vehicular de una compañía. 

El servicio implementa operaciones CRUD completas sobre vehículos y entidades asociadas, garantizando persistencia estructurada mediante **Prisma ORM**, validación de tipos estricta y documentación interactiva de endpoints con **Swagger/OpenAPI**

### ✨ Características Principales

- **Gestión Vehicular (CRUD):** Endpoints para registro, consulta, actualización y eliminación de vehículos.
- **Capa de Persistencia con Prisma:** Modelado relacional, migraciones automáticas y consultas tipadas de alto rendimiento con Prisma ORM.
- **Documentación de API:** Especificación interactiva OpenAPI/Swagger (`bryanedwardswagger.json`) para facilitar la integración frontend y pruebas de endpoints.

### 🧰 Stack Tecnológico

- **Runtime & Lenguaje:** Node.js, TypeScript (97.2%)
- **ORM / Base de Datos:** Prisma ORM
- **Testing:** Jest
- **Documentación:** Swagger / OpenAPI Spec
- **CI/CD & DevOps:** GitHub Actions, Procfile
